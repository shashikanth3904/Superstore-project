# Superstore-project
# Retail Sales Analysis and Sales Prediction Using Machine Learning

## Project Overview

This project analyzes a real-world retail sales dataset and builds a machine learning model to predict sales.

## Objective

Perform end-to-end data analysis, visualize trends, and predict sales using Linear Regression.

## Dataset

SampleSuperstore.csv

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow

1. Load the dataset
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Build Linear Regression Model
6. Model Evaluation
7. Visualizations
8. Conclusion

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Outcome

Successfully analyzed retail sales data and developed a predictive model for sales forecasting.
